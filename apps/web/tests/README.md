# 学习页回归

运行 `pnpm --filter @en/web test:learn` 检查音频状态与异步竞态。测试使用真实 hook 和模拟媒体事件，不需要联网或启动后端。

运行 `pnpm web` 后访问 `http://127.0.0.1:8080/tests/learn-preview.html`，可使用三个测试单词检查界面。此页面在内存中拦截所有学习 API，不写真实学习记录，也不加入正式构建入口。发音仍使用真实在线音频，偏好设置与正式页面共用本地存储。

手动回归步骤：

1. 点击释义或空白处输入 `s`：首字母进入输入区，输入数只增加 1。
2. 输入 `t`，打开设置，尝试字母、左右方向键、Ctrl + ;：底层答案、题号和计时保持不变。Tab / Shift + Tab 焦点只在面板内部循环。
3. Esc 关闭设置：保留 `st`，恢复计时；开启自动发音时重读当前词。
4. Esc 暂停；Shift / Ctrl 不恢复。按字母、空格或 Enter 恢复：恢复键不计入答案和统计。
5. 输入错误字母：出现错误反馈，错误数增加 1。连续三次错误显示答案。正确输入 `style` 后显示成功反馈，Enter 进入下一词。
6. 美音 / 英音都可试听；喇叭随播放开始和结束切换状态。断网时优先尝试同口音本地语音，无可用语音时显示重试提示。
7. 关闭音效后不再产生按键、错误、完成提示音；音量滑块禁用。恢复音效后可调整音量。
8. 切到其他标签页暂停，再回来继续；设置中离开页面后，关闭设置仍保持暂停。暂停时间不计入练习及单词答题时长。
9. 检查浅色、深色和窄屏布局；移动端点击输入区域可调出键盘。
10. 等当前词加载完成后连续重播、暂停恢复、切换口音：复用预加载音频，不重复下载；下一词提前加载。首次加载或慢网下仍允许显示真实加载状态。

浏览器可能要求首次交互后才能播放音频；被拦截时显示操作提示，并在用户开始输入或点击喇叭后重试。音频地址可用性检查不能代替真实设备的听感验收。
